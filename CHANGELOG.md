## [0.1.0] - 2026-09-26

### Added

- Native macOS wrapper and WorkBae editorial interface
- WhatsApp text-export import for common iPhone and Android formats
- Daily contribution detection and editable work-log entries
- Daily and monthly Markdown and CSV export
- Optional local Ollama summarization for Bangla, Banglish, and English
- Universal Apple Silicon and Intel build pipeline
