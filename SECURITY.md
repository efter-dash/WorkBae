# Security policy

## Supported version

Security fixes are applied to the latest release of WorkBae.

## Reporting a vulnerability

Please report vulnerabilities privately through the repository's **Security → Report a vulnerability** page. Do not open a public issue for a security problem.

Include the affected version, macOS version, impact, and reproduction steps. Use synthetic data only; never include a real WhatsApp export or client information.

## Scope

Particularly useful reports include unintended network access, exposure of locally stored chat data, unsafe file handling, or a way for imported content to execute code.
